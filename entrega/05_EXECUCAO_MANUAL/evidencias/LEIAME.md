# Evidências da execução manual

Uma evidência por execução, com o nome `EX-NNN_CT-NNN_AAAA-MM-DD.ext`:

- `EX-001_CT-007_2026-11-20.png` — captura de tela (casos pela interface)
- `EX-014_CT-014_2026-11-20.txt` — requisição e resposta HTTP (casos pela API, `curl -i`)
- Sufixo `_a`, `_b`... quando o caso tem várias partes: `EX-003_CT-003_2026-11-20_a.png`

O nome do arquivo deve aparecer na coluna Evidência de `dados/execucoes.csv`. As evidências não podem ser editadas depois de salvas. Instruções completas em `../P06_Roteiro_Execucao.md`.
